# Code of Conduct

We are committed to a welcoming, respectful, and harassment-free community.
Participants are expected to be considerate, use inclusive language, accept
constructive feedback, and focus on what is best for the community.

Unacceptable behavior includes harassment, discrimination, personal attacks,
and publishing private information without permission. Project maintainers may
remove content or restrict participation when necessary to protect the community.

Report conduct concerns privately to the repository maintainers.
